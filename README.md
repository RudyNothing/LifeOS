# LifeOS

LifeOS is an offline personal life management application being developed as a Project Based Learning project.

The idea behind LifeOS is simple: instead of using different apps for tasks, notes, schedules, expenses, journals and private information, LifeOS aims to bring these parts of everyday life together in one place.

The application is designed to work offline, with the user's data stored locally on the device.

## What LifeOS Includes

LifeOS is planned around six main modules:

### Knowledge Hub
A place to save and organize personal notes, information and things worth remembering.

### Task & Planner
Helps users create tasks, set priorities and keep track of what needs to be done.

### Schedule Manager
Used for managing events, appointments and other scheduled activities.

### Finance Manager
Allows users to record their personal income and expenses and keep track of their finances.

### Journal & Memories
Provides a private space for writing journal entries and saving important memories.

### Secure Vault
A protected section for storing sensitive personal information.

The application will also have supporting features such as a dashboard, unified timeline, search, reminders and local backup/restore.

## Technology

LifeOS is being developed using native Android technologies.

- Java
- XML
- Android SDK
- Room
- SQLite
- Android Studio

The project follows an offline-first approach. The core application does not depend on a server, Firebase or an internet connection to store or access personal data.


## Project Status

LifeOS is currently under active development.

The database foundation is complete for the current development phase. The user interface, repositories, remaining data-access components and the individual modules will be implemented in subsequent phases.

The project is intended as an academic project as well as a practical exploration of building a complete offline Android application using Java.
